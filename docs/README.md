# Screenshots go here

The GitHub page needs one screenshot of the running interface, near the top of
`README.md` and `README.fr.md`. It is the single thing that decides whether a
visitor reads any further.

## How to make it

1. Start the app, let a render finish so the page has real content in it
   (caption filled, a track in the player, the log showing something).
2. Make the browser window reasonably wide — around 1400 px — so the two
   columns sit side by side rather than stacking.
3. **Shift-Command-4**, then press **Space**, then click the browser window.
   That captures the window with its rounded corners and shadow, which reads
   better than a rectangle.
4. Save it here as `screenshot.png`.
5. Add this line to both READMEs, just under the title:

```markdown
![The interface](docs/screenshot.png)
```

## Please check before publishing

A screenshot shows whatever was on screen. Check the caption box, the batch
name and the file paths in the log for anything personal before it goes public.
